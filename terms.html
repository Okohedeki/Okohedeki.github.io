1. Purpose

This website documents a private Model Context Protocol (MCP) server operated by Okohedeki. The MCP is intended to retrieve keyword ideas, historical search metrics, competition indicators, bid ranges, and forecasts for Google Ads accounts the operator owns or is authorized to manage.

2. Authorized use

Use is limited to the operator's authorized MCP client and eligible advertising accounts. The MCP server is not made available for use by clients, customers, or other external parties.

3. Read-only limitation

The planned MCP does not register tools that create, edit, or delete campaigns, ads, ad groups, budgets, targeting settings, or account keywords. Tool results are informational and do not execute advertising decisions.

4. No third-party MCP access

The MCP server will not be published as a general endpoint, share the Google Ads API developer token, or allow third parties to make requests through the operator's credentials. Credentials remain server-side and are not returned in tool responses.

5. Google services

Use of Google Ads services remains subject to Google's applicable terms, policies, account permissions, and service availability. Google Ads is a trademark of Google LLC. This MCP is not endorsed by or affiliated with Google.

6. Availability and changes

The MCP is in development and may change or be unavailable. If its API use materially changes, the public description and applicable policy documentation will be updated before the expanded use is placed into production.

7. Contact

Questions about this site or the tool can be directed to Okohedeki through the operator's public GitHub profile.
