Safety model

Useful to the agent. Account control stays human.

+ The MCP will

  • Validate every requested tool and parameter
  • Restrict queries to authorized account IDs
  • Return structured research results to the operator
  • Keep credentials and developer token server-side

− The MCP will not

  • Create or modify campaigns, ads, budgets, or keywords
  • Expose a public or third-party MCP endpoint
  • Forward OAuth credentials or the developer token
  • Turn a recommendation into an advertising action

Access and data

Private by design and narrow by default.

The MCP is intended for one operator and only for Google Ads accounts that operator owns or is authorized to manage.

AUTH

Credentials stay server-side

Google OAuth and the developer token will be handled by the MCP server, not returned in model context or tool responses.

SCOPE

Accounts are allowlisted

Every tool call will require an eligible customer ID and be rejected when the account is outside the operator's authorized scope.

SHARE

No external MCP users

The server will not be published as a general service or used to provide other people access through the operator's credentials.

Detailed handling practices and site terms are published separately.
